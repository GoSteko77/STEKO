# STEKO

Climb with Purpose — a goal tracker for Christians, built by Go Steko LLC.

STEKO is a free, installable Progressive Web App (PWA) that runs entirely in the web browser. It is not distributed through the Apple App Store or Google Play Store. Add it to your home screen from Chrome, Safari, Edge, or Firefox for an app-like experience.

## Technology

- **Expo Router + React Native** — web-first PWA build
- **TypeScript** — type-safe UI and business logic
- **LocalStorage / AsyncStorage** — all data stays on the user's device; no server, no cloud sync
- **Manual export/import** — JSON backup files for cross-device transfer
- **Service Worker** — offline caching and installable PWA support
- **GitHub Actions + Pages** — automated build and deployment

## Local development

Run these commands from the `expo/` folder inside the project:

```bash
bun i
bun run start-web
```

## Build and deploy

Pushing to the `main` branch of the `gosteko77/STEKO` repository triggers the GitHub Actions workflow in `.github/workflows/deploy.yml`. The workflow exports the PWA build, copies the manifest and service worker, and deploys to GitHub Pages at `gosteko77.github.io/STEKO/`.

### Manual web build

```bash
bun run export-web
```

The static export is written to `dist/` and can be previewed locally or uploaded to any static host.

## Features

- **Free for everyone** — no subscription, no paywall, no gated content
- **No sign-in required** — all data is stored locally on your device
- **Full offline support** — the app works entirely without an internet connection
- **Home screen install** — add STEKO to your phone or desktop from the browser
- **Manual backup** — export your data to a JSON file and import it on another device
